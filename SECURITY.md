# Security Policy

## Supported versions

Only the latest release on `main` receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately via
[GitHub Security Advisories](https://github.com/DeM-Conve/project__hcdb/security/advisories/new).

You should get an acknowledgement within 7 days. Data-loss or durability bugs
(e.g. acknowledged writes lost after a crash) are treated as security-severity.
